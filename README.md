# Sudoku DIO

Este é um projeto de Sudoku desenvolvido como parte do curso DIO. O objetivo é criar um jogo de Sudoku com diferentes níveis de dificuldade (fácil, médio e difícil) e uma interface gráfica amigável.

## Funcionalidades

- Jogo de Sudoku com três níveis de dificuldade: fácil, médio e difícil.
- Interface gráfica intuitiva.
- Botões para reiniciar o jogo, verificar o status do jogo, obter dicas e selecionar a dificuldade.
- Validação de erros no tabuleiro.

## Tecnologias Utilizadas

- Java
- Swing (para a interface gráfica)
